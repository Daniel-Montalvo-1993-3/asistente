🔧 Guía: Instalar CUDA para Whisper

  1. Comprueba que tu driver NVIDIA esté actualizado (nvidia-smi).
  2. Instala las librerías CUDA de Python: 
    pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
  3. Reinicia el núcleo desde esta pestaña (botón abajo).
  4. Vuelve a Sistema; CUDA (para Whisper en GPU) debería decir ✅ Lista.
  5. En Configuración, pon Dispositivo = Auto y modelo medium (tu RTX soporta hasta large-v3).

🔗 Integraciones MCP (Gmail, Calendar, Drive…)

Los MCPs son conectores oficiales de Anthropic que le dan a Claude acceso a servicios externos. Como Jarvis usa Claude Code como cerebro, cualquier MCP que instales en Claude Code quedará disponible aquí automáticamente.

Cómo habilitar un MCP

  1. En tu terminal, corre: claude mcp (interactivo) o claude mcp add <nombre>.
  2. Para los oficiales de claude.ai (Gmail, Calendar, Drive, Slack…), ve a claude.ai → Settings → Connectors, conéctalos con tu cuenta y autoriza. Jarvis los heredará automáticamente.
  3. Reinicia el núcleo desde Configuración y pregúntale a Jarvis algo del servicio ("¿Qué correos tengo sin leer?").
Nota: Los MCPs requieren autorización OAuth del usuario — Jarvis no puede hacerla por ti. Una vez autorizados, los usa sin fricciones.

🧠 Cambiar de cerebro

En Configuración → Cerebro puedes alternar entre:

  • Claude Pro (nube): más capaz, usa tu plan, puede acceder al vault y ejecutar comandos.
  • Ollama local (gratis): corre un modelo en tu RTX 2070 SUPER. Sin internet. Solo conversa (no toca vault ni ejecuta).

Para Ollama: instala desde ollama.com, luego ollama pull qwen2.5-coder:7b.
